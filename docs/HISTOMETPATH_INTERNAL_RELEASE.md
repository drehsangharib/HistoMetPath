# HistoMetPath Internal Development Release

This source-only release packages the reproducible code, configurations, tests, decision report, model card, release metadata, and SHA-256 manifest for the completed internal CAMELYON16 development cycle. Runtime data, embeddings, whole-slide images, checkpoints, model artifacts, and generated outputs are excluded.

The release does not introduce a new performance claim. Spatial v2 remains the primary development baseline; dual-view concatenation remains secondary and exploratory. A new untouched evaluation cohort is the required next scientific step.
