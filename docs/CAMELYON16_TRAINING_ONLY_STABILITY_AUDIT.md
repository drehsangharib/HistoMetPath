# CAMELYON16 Training-Only Repeated Stability Audit

This milestone evaluates the five frozen interpretable baseline families using only the 30 training slides. The six validation slides remain untouched and the consumed test cohort remains prohibited.

The audit uses ten predeclared seeds and five-fold repeated stratified cross-validation, producing 50 outer folds. Every outer prediction is generated by models fit only on the corresponding outer training partition. Logistic stacking uses three-fold inner out-of-fold base probabilities within each outer training partition.

Fold evaluation uses a fixed 0.5 decision threshold to avoid threshold calibration on outer test folds. The audit reports metric means and standard deviations, fold-win frequencies, out-of-fold prediction variability, and coefficient-direction stability. The existing six-slide validation result remains frozen as an external development check and is checksum-recorded but not loaded for modeling.
